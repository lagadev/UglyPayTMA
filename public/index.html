পেমেন্ট রিসিভ করা ফোনে এই অ্যাপটি ইনস্টল করুন। এটি শুধু bKash/Nagad/Rocket/Upay-এর SMS আপনার সার্ভারে পাঠায়, বাকি কোনো SMS নয়।

APK লিংক সেট করা নেই (wrangler.toml → APK_URL)।
  1. APK ডাউনলোড করে ইনস্টল করুন (অজানা উৎস থেকে ইনস্টলের অনুমতি লাগতে পারে)।
  2. অ্যাপ খুলে নিচের Server URL ও Token বসিয়ে সেভ করুন।
  3. SMS পারমিশন দিন। Android ১৩+ হলে App info → ⋮ → "Allow restricted settings" দিতে হতে পারে।
